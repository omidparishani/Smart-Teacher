# چک‌لیست بازبینی نهایی پیش از استقرار پروداکشن (Production Readiness Checklist)

این چک‌لیست باید پیش از اتصال اولین کاربر یا اجرای زنده روی دامنه اصلی توسط تیم فنی بررسی و تیک زده شود:

---

## ۱. امنیت و احراز هویت
- [ ] **رازهای امنیتی:** آیا متغیرهای `JWT_SECRET`, `ENCRYPTION_MASTER_KEY`, `DB_PASSWORD`, `REDIS_PASSWORD` همگی کلیدهای تصادفی قوی و غیرپیش‌فرض هستند؟
- [ ] **عدم افشای رازها:** آیا هیچ کلید واقعی در گیت، داکرفایل‌ها، پیام‌های خطا، لاگ‌های سیستمی یا خروجی Swagger ثبت نشده است؟
- [ ] **فیلتر محدودیت نرخ (Rate Limiting):** آیا محدودیت نرخ روی تمامی مسیرهای حساس `/auth/login`, `/auth/eitaa`, `/auth/refresh`, `/auth/logout` فعال است؟
- [ ] **نگه‌بان ضد بازپخش (Replay Guard):** آیا `APP_REDIS_ENABLED=true` در محیط عملیاتی فعال است تا در صورت راه‌اندازی مجدد سرور، فینگرپرینت‌های احراز هویت پاک نشوند؟
- [ ] **سیاست CORS:** آیا `APP_CORS_ALLOWED_ORIGINS` روی دامنه‌های واقعی شما ست شده و مقدار ستاره (`*`) ندارد؟

## ۲. یکپارچه‌سازی با ایتا
- [ ] **تنظیم توکن ربات:** آیا `APP_EITAA_BOT_TOKEN` و `APP_EITAA_APP_TOKEN` ست شده‌اند؟
- [ ] **کانفیگ Nginx و iframe:** آیا هدر `Content-Security-Policy` برای مسیر مینی‌اپ معلمان به درستی مبدأ `https://eitaa.com` را مجاز می‌داند؟
- [ ] **تست ارسال:** آیا قبل از ارسال به گروه‌ها/کانال‌های واقعی، پیام تستی به شناسه آزمایشی ارسال و تحویل موفق تأیید شده است؟

## ۳. پایداری داده و معماری
- [ ] **عدم افشای پورت‌های دیتابیس:** آیا پورت‌های `5432` و `6379` به بیرون از سرور بسته هستند و تنها از طریق شبکه داخلی داکر در دسترس‌اند؟
- [ ] **جداسازی مستأجر:** آیا درخواست‌های داده با هدر مستأجر و `@TenantId` بررسی می‌شوند تا هیچ نشت اطلاعاتی بین مدارس رخ ندهد؟
- [ ] **پشتیبان‌گیری خودکار:** آیا Cron Job برای پشتیبان‌گیری دوره‌ای روزانه از دیتابیس Postgres فعال شده است؟

## ۴. رابط‌های کاربری (Frontend & Admin)
- [ ] **بودجه باندل:** آیا خروجی `npm run size-check` در مینی‌اپ زیر سقف ۱۵۰ کیلوبایت (حدود ۱۳۲ کیلوبایت) است؟
- [ ] **تست‌ها و تایپ‌چک:** آیا خروجی `npm run typecheck` و `npm run test` در هر دو پوشه `miniapp` و `admin-panel` ۱۰۰٪ سبز است؟
- [ ] **پنل ادمین:** آیا امکانات CRUD، تغییر نقش کاربران، تمدید اشتراک‌ها و لاگ‌های حسابرسی به درستی کار می‌کنند؟
